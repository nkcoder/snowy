# External Integrations

**Analysis Date:** 2026-04-26

## External Services

**PostgreSQL (user-configured databases):**
- Role: The primary data target — all schema introspection and query execution runs against user-provided PostgreSQL instances
- No hardcoded connection; every connection is read from `~/.snowy/config.json` at runtime
- Development/demo database: Docker container (`docker/docker-compose-postgresql.yml`) — `postgres:latest` image, port 5432, database `mydatabase`, user `myuser`

**No cloud APIs, analytics, telemetry, or third-party SaaS integrations are present.** The app is fully offline/local.

## APIs & Protocols

**Wails frontend-to-backend bridge:**
- All frontend→backend calls go through auto-generated JS wrappers in `frontend/wailsjs/go/main/App.js`
- Do not edit these files by hand — they are regenerated by `wails dev` / `wails build`
- In dev mode, Wails uses a WebSocket connection between the Vite dev server and the Go process
- In production, the frontend is embedded into the Go binary via `//go:embed all:frontend/dist` (`main.go:11`) and served by Wails' internal Echo HTTP server

**Backend methods exposed to frontend (all on `App` struct in `app.go`):**

| Method | Signature | Purpose |
|--------|-----------|---------|
| `GetConfig` | `() (Config, error)` | Load full config |
| `SaveConfig` | `(Config) error` | Persist full config |
| `UpdateDatasource` | `(Datasource) error` | Update single datasource |
| `TestDatasource` | `(host, port, db, user, pass, sslMode) TestConnectionResult` | Test-only connection |
| `ListSchemas` | `(dsId) ([]SchemaItem, error)` | PostgreSQL schema list |
| `ListTables` | `(dsId, schema) ([]TableItem, error)` | Tables + views in a schema |
| `ListColumns` | `(dsId, schema, table) ([]ColumnItem, error)` | Column metadata |
| `ExecuteQuery` | `(dsId, sql) (*QueryResult, error)` | Run arbitrary SQL |
| `GetCompletions` | `(dsId) (*CompletionSet, error)` | All schemas/tables/columns for autocomplete |
| `SaveQuery` | `(dsId, filename, sql) error` | Write `.sql` file to disk |
| `ListSavedQueries` | `(dsId) ([]SavedQuery, error)` | List saved `.sql` files |
| `LoadSavedQuery` | `(dsId, filename) (string, error)` | Read saved query content |

| `RecordHistory` | `(dsId, sql, rowCount, durationMs) error` | Append to history JSONL |
| `GetQueryHistory` | `(dsId, limit) ([]HistoryEntry, error)` | Read history, newest first |

**PostgreSQL wire protocol (via pgx v5):**
- Driver: `github.com/jackc/pgx/v5` — direct PostgreSQL wire protocol, no ORM
- Connection string format: `postgres://<user>:<pass>@<host>:<port>/<db>?sslmode=<mode>` (`db_service.go:81`)
- SSL modes supported: `disable`, `require`, `verify-ca`, `verify-full`
- Connection pattern: one fresh `pgx.Conn` per call; no connection pool (`db_service.go:58-89`)
- Query timeout: 10 seconds per connection (`db_service.go:80`)
- Schema introspection queries target `information_schema.schemata`, `information_schema.tables`, `information_schema.columns`

**Wails runtime dialog API:**
- `runtime.SaveFileDialog` — used by the frontend for CSV export (called via `window.runtime` injected by Wails)

## Auth & Security

**No authentication layer** — the app is a local desktop tool with no login/session system.

**Database credentials:**
- Stored in plaintext JSON at `~/.snowy/config.json` (`config.go:19` comment: "Plain text for now; keychain integration planned")
- File permissions: `0644` (world-readable on Linux/macOS)
- Credentials are read from config on every DB call — no in-memory credential caching beyond what pgx holds for the lifetime of a single connection

**Config file access:**
- Protected by `sync.RWMutex` inside `ConfigManager` for concurrent read/write safety (`config.go:37`)
- No encryption at rest

**SSL/TLS to PostgreSQL:**
- Configurable per datasource via `sslMode` field
- Defaults to `disable` when not set (`db_service.go:76-79`)

**No API keys, OAuth tokens, webhooks, or external auth providers are used.**

## Data Storage

**All storage is local filesystem under `~/.snowy/`:**

| Path | Format | Purpose | Managed by |
|------|--------|---------|-----------|
| `~/.snowy/config.json` | JSON | Projects and datasources (including credentials) | `config.go` / `ConfigManager` |
| `~/.snowy/queries/<dsId>/<filename>.sql` | Plain text SQL | User-saved query files | `query_service.go` |
| `~/.snowy/history/<dsId>.jsonl` | Newline-delimited JSON | Query execution history | `history_service.go` |

**In-memory cache:**
- `DbService.completionCache` — `sync.Map` keyed by `dsId` storing `*CompletionSet`; populated on first `GetCompletions` call, evicted only on process restart (`db_service.go:51`, `db_service.go:171-176`)

**No external databases, object storage, caching services (Redis etc.), or message queues are used.**
